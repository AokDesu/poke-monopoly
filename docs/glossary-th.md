# คำศัพท์ภาษาไทย — Poke Monopoly

ใช้คำไทยในตารางนี้ให้ตรงกันทั้งหน้าจอ ข้อความสถานะ และข้อความในเกม โดยคงคำอังกฤษไว้เป็นแหล่งอ้างอิงสำหรับทีม
อ้างอิง [สเปก §3 และ §3.1](SPEC-v1.0-PokeMonopoly.md#3-user-flow-and-screens); ความหมายของกติกามาจาก §4 และ §5.6 ไม่ใช่กติกาใหม่

## คำศัพท์

| English source term | คำไทยที่ใช้ | ความหมายในเกม |
|---|---|---|
| Ball | บอล | คำรวมของไอเทมที่ใช้ในการพยายามจับโปเกมอน |
| Poké Ball | มอนสเตอร์บอล | บอลพื้นฐานสำหรับจับโปเกมอน |
| Great Ball | ซูเปอร์บอล | บอลที่ช่วยให้จับโปเกมอนได้ง่ายกว่ามอนสเตอร์บอล |
| Ultra Ball | ไฮเปอร์บอล | บอลที่ช่วยให้จับโปเกมอนได้ง่ายกว่าซูเปอร์บอล |
| Start | จุดเริ่มต้น | ช่องเริ่มต้นบนกระดาน ซึ่งให้รายได้และเปิดช่วงขายเมื่อเดินผ่านหรือหยุดตามเงื่อนไขของเอนจิน |
| Lap | รอบ | รอบที่เอนจินนับเมื่อผู้เล่นเดินผ่านหรือหยุดที่จุดเริ่มต้นและได้รับรายได้ตามเงื่อนไข ไม่ใช่เทิร์น |
| Wild | ช่องโปเกมอนป่า | ช่องบนกระดานที่พบโปเกมอนให้เลือกจับหรือปล่อย |
| Shop | ร้านค้า | ช่องที่ซื้อบอลหรือไอเทมได้ หรือเลือกข้ามโดยไม่ซื้อ |
| Gym | ยิม | ช่องท้าประลองเพื่อรับเข็มกลัดและเลือกรางวัลเมื่อชนะ |
| Event | เหตุการณ์ | ช่องที่เปิดการ์ดเหตุการณ์และใช้ผลตามที่เอนจินกำหนด |
| Sell Phase | ช่วงขาย | ช่วงที่เลือกขายโปเกมอนเมื่อผ่านหรือหยุดที่จุดเริ่มต้นตามเงื่อนไข |
| Rescue Starter | โปเกมอนเริ่มต้นช่วยเหลือ | โปเกมอนเริ่มต้นประจำคลาสที่ได้รับเมื่อทีมว่างหลังยืนยันการขาย ไม่มีมูลค่าขาย ไม่รับโบนัสคลาส และแลกเปลี่ยนไม่ได้ |
| Tired | เหนื่อย | สถานะที่ทำให้โปเกมอนไม่พร้อมประลองและขายได้ราคาลดลง จนกว่าสถานะจะหมดหรือถูกลบ |
| Deal Card | การ์ดแลกเปลี่ยน | ข้อเสนอแลกเปลี่ยนที่ระบุทรัพย์สินและเหรียญชัดเจน และต้องยืนยันก่อนเอนจินโอนให้ทั้งสองฝ่ายพร้อมกัน |
| Promise | คำสัญญา | ข้อตกลงไม่โจมตีที่มีผลเมื่อผู้รับยอมรับ และสิ้นสุดตามเทิร์นที่เอนจินกำหนด |
| trust | ความไว้วางใจ | ค่าความสัมพันธ์ระหว่างผู้เล่นที่เอนจินปรับจากหลักฐานการรักษาหรือผิดคำสัญญา |
| Backup bot mode | โหมดบอตสำรอง | สถานะที่ใช้บอตสำรองตัดสินใจแทน Jev โดยยังเล่นตามกติกาเดิม |
| class | คลาส | บทบาทที่กำหนดโปเกมอนเริ่มต้น ความสามารถติดตัว และไอเทมประจำคลาส แยกจากบุคลิก |
| personality | บุคลิก | แนวทางการตัดสินใจของคู่แข่ง AI ซึ่งไม่เปลี่ยนกติกาหรือสิ่งที่มองเห็นได้ |
| difficulty | ระดับความยาก | รูปแบบข้อมูลและวิธีเลือกการกระทำของ AI โดยทุกระดับมองเห็นข้อมูลตามสิทธิ์เดียวกัน |

ชื่อบอลใช้รูปแบบจากเว็บไซต์โปเกมอนภาษาไทยอย่างเป็นทางการ:
[มอนสเตอร์บอล](https://asia.pokemon-card.com/th/card-search/detail/464/),
[ซูเปอร์บอล](https://asia.pokemon-card.com/th/card-search/detail/6788/),
[ไฮเปอร์บอล](https://asia.pokemon-card.com/th/card-search/detail/5112/).
ใช้แหล่งนี้อ้างอิงเฉพาะชื่อ ไม่ได้นำกติกาของการ์ดเกมมาใช้

## คีย์ข้อความสำหรับสเปก §3.1

ข้อความทั้งหมดอยู่ใน `web/src/i18n/th.ts` และอ่านผ่าน `t(key)` ตามรูปแบบเดิม
ตารางนี้ระบุคีย์ที่ต้องมี ไม่ได้เชื่อมข้อความเข้ากับหน้าจอหรือเพิ่มกติกาให้เอนจิน

| สถานการณ์ตามลำดับใน §3.1 | คีย์ข้อความ UI |
|---|---|
| มีการกระทำที่ทำได้เพียงอย่างเดียว | `turn.onlyLegalAction` |
| รายการตัวเลือกยังว่างหลังกรองบุคลิก | `turn.noAvailableOptions` |
| พบโปเกมอนแต่ไม่มีบอล | `encounter.catch`, `encounter.noBall`, `encounter.release` |
| เหรียญไม่พอซื้อของในร้านค้า | `shop.notEnoughCoins`, `shop.skip` |
| ถือไอเทมครบจำนวนสูงสุดในร้านค้า ซื้อไอเทมเพิ่มไม่ได้ แต่ยังซื้อบอลได้ | `shop.itemsFull`, `shop.skip` |
| Jev หมดเวลา ถูกจำกัดคำขอ หรือผิดพลาดระหว่างตกลงแลกเปลี่ยน | `ai.backupBadge`, `ai.backupUnavailable`, `deal.reconfirmAfterFallback`, `deal.confirm` |
| คำตอบไม่อยู่ในตัวเลือก หรืออ้างอิงข้อเสนอคนละฉบับ | `ai.backupInvalidAnswer`, `ai.backupRevisionMismatch` |
| ความมั่นใจต่ำกว่าเกณฑ์ ตาม §5.6 สำหรับ Normal/Hard | `ai.backupLowConfidence` |
| คู่แข่ง AI ทุกคนใช้บอตสำรอง | `ai.allBackupBanner` |
| ตีความข้อความแชตไม่ได้ | `chat.unclassified` |
| ข้อความขอให้ทำผิดกติกาหรือเปิดเผยข้อมูลลับ | `chat.manipulationRefused` |
| กลับมาเล่นหลังปิดเบราว์เซอร์ระหว่างเทิร์น AI | `game.resumedAiTurn` |
| ทีมว่างหลังช่วงขาย | `sell.rescueStarter` |
| กองการ์ดเหตุการณ์หมด | `event.deckReshuffled` |

- `chat.*` เป็นข้อความสถานะของ UI ไม่ใช่บทพูดของ AI; คลังบทพูดแยกตามบุคลิกและความไว้วางใจอยู่รอบพัฒนาถัดไปตาม §5.7
- แสดง `ai.backupBadge` เฉพาะเมื่อ AI ใช้บอตสำรองจริง และแสดง `ai.allBackupBanner` เพียงแถบเดียวเมื่อทุก AI ใช้บอตสำรอง
- ข้อความปุ่มที่ใช้ไม่ได้ต้องแสดงพร้อมเหตุผล และปุ่มต้องเป็นสีเทาตาม §3.1; แค็ตตาล็อกข้อความไม่ได้ควบคุมสถานะปุ่ม
- ข้อความไม่ใส่ราคา จำนวน โอกาสสำเร็จ หรือผลคำนวณตายตัว ทุกตัวเลขที่จะแสดงต้องมาจากเอนจิน
- `web/src/i18n/th.test.ts` ระบุคีย์ของแต่ละสถานการณ์อย่างชัดเจน และตรวจว่าทุกคีย์มีข้อความไทยผ่าน `t(key)` โดยไม่ล็อกถ้อยคำเพื่อให้ทีมปรับภาษาได้
